# Reports

This directory contains generated outputs produced during data preparation, model training, and evaluation.

The notebooks may generate artefacts that support analysis, interpretation, and reporting of experimental results.

## Typical Contents

Examples include:

- Evaluation summaries
- Performance comparison tables
- Confusion matrix figures
- Learning curves
- Training logs (if exported)
- Statistical comparison results

Example structure:

```
reports/
├── figures/
├── tables/
└── README.md
```

## Notes

This directory is intentionally kept lightweight.

Most outputs generated by the notebooks are stored within the corresponding `models/` directory to preserve experiment-specific artefacts.

Researchers may optionally export publication-quality figures and tables here for inclusion in reports, dissertations, or journal manuscripts.
